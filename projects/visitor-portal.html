Visitor Portal — WiFi Password Rotation

ASP.NET Core • Angular • SQL Server

Overview

A secure visitor portal that shows visitors the current WiFi password after authentication. Passwords are rotated automatically by a background service to keep access short-lived and auditable.

Features

  • Visitor authentication (OTP / token)
  • Short-lived WiFi password display
  • Background service for automatic password rotation
  • Telemetry and logs with Kusto (KQL) for diagnostics
